## Project Description
A responsive Weather Dashboard application built to master asynchronous JavaScript, Fetch API interactions, error management, and persistent local storage through the OpenWeatherMap API.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+, Async/Await, Fetch API)
- OpenWeatherMap API
- GitHub Actions

## Features
- **Real-time Weather Data:** Search global cities to fetch live temperature, descriptions, wind speed, pressure, and humidity.
- **Robust Error Handling:** Clear status notifications for invalid cities, network disruptions, or API key propagation delays.
- **Recent Search History:** Automatically caches up to 5 unique recent search queries using `localStorage` for rapid re-searching.
- **Secure Configuration Management:** Utilizes a decoupled `config.js` framework integrated with GitHub Actions secrets to prevent API key leaks.
